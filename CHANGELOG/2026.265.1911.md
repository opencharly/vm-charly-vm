**Namespace note (why `/charly-<plugin>:<skill>` references are kept, not
rewritten).** A skill's canonical reference is `/charly-<family>:<skill>`, where
`<family>` is the skill entity's `family:` field — a REQUIRED field on every
`skill:` entity (`candy/plugin-marketplace` `emit_skills.go:28` routes a skill to
`plugins/<familyName>/skills/<name>`, and each plugin's `name` is
`charly-<family>`). The move does NOT change `family:` (the moved entity keeps
its family), so a `/vm-vm`-style reference
continues to resolve. Example: the moved `omarchy-vm` skill keeps `family: vm`,
emits to `plugins/vm/skills/omarchy-vm`, and the `vm` plugin is `charly-vm`
(`marketplace/vm/.claude-plugin/plugin.json`). So those references are correct as
written and are not stale identifiers.
